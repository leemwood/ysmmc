# 视频首发规范

说明视频首次投稿时来源链接、标题、简介、分区、封面、标签、授权、可见性和持续可访问性的要求。

## 适用范围

这篇规范适用于第一次向 NexusMC 提交外部平台视频。当前视频投稿只保存来源链接和站内展示信息，不上传或托管视频原文件。

当前支持：

-   Bilibili
-   腾讯视频
-   抖音

视频首发应让用户和审核人员能够判断：

-   视频来自哪里，链接是否可以持续访问。
-   标题、简介、封面是否准确反映内容。
-   视频与 Minecraft 或 NexusMC 社区有什么关系。
-   投稿人是否有权发布或推荐该视频。
-   视频失效、下架或内容变化后由谁维护。

正式投稿前需完成 [创作者开通与协议确认](/docs/site-info/creator-onboarding/)。状态和接口解析流程见 [视频投稿流程](/docs/operations/video-submission-flow/)。

## 来源链接

`sourceUrl` 必须指向受支持平台上的具体视频详情页。

推荐使用：

-   平台生成的公开视频详情链接。
-   可以在未登录或普通访问状态下打开的稳定链接。
-   不依赖一次性参数、临时授权或私密分享权限的地址。

不要提交：

-   用户主页、搜索页、频道页或合集首页。
-   直播间、预约页或已经结束的临时直播链接。
-   多次跳转的短链、推广链接或聚合页。
-   需要购买、特殊账号权限或私下索取密码才能观看的链接。
-   与实际投稿视频不一致的替代链接。

WARNING

站内能解析链接不等于视频一定适合公开展示。来源视频仍需保持可访问，且内容、标题和授权符合要求。

## 标题

标题应准确说明视频主题。系统可以读取平台标题，但投稿前仍应人工检查。

推荐：

```
1.21 红石分类机搭建教程
Paper 服务器性能排查：从 MSPT 到插件定位
```

不推荐：

```
震惊！所有玩家都不知道
史上最强，错过后悔
点进来就懂了
```

标题要求：

-   与来源视频标题和实际内容一致。
-   可以适度精简平台标题，但不能改变原意。
-   不堆砌分区名、标签、表情或无关关键词。
-   系列视频应写明期数或章节，避免同名投稿无法区分。
-   不冒充官方、原作者或其他组织发布。

## 简介

简介虽然不是接口必填字段，但首发时建议完整填写。它应帮助用户在播放前判断视频是否适合自己。

建议包含：

-   视频解决的问题或主要看点。
-   适用的 Minecraft 平台、版本或服务端环境。
-   视频作者或来源关系，特别是非原创投稿。
-   需要的前置资源、模组、插件或关联帖子。
-   时间敏感内容的录制或核对时间。

简介不能只写“见视频”“三连支持”或一串外链。

## 分区与标签

分区应选择与视频主要内容最接近的一项。未指定分区时，系统会使用当前默认分区，但这不代表默认分区一定准确。

标签会去重并最多保留 10 个，通常选择 2 到 5 个即可。标签应描述：

-   内容类型，例如教程、实况、测评。
-   主要主题，例如红石、建筑、模组开发。
-   相关平台或版本，仅在确实重要时添加。

不要添加与视频无关的热门标签，也不要重复标题中的每个词。

## 封面

未手动上传封面时，系统会尝试读取来源平台封面。无论使用哪种方式，都需要确认：

-   封面来自视频本身或已获授权的素材。
-   主体清晰，裁切后仍能识别。
-   不包含虚假界面、伪造数据或视频中不存在的内容。
-   不使用低俗、惊吓、误导或与主题无关的画面吸引点击。
-   不暴露账号、Token、后台地址、真实姓名等敏感信息。

前台上传封面时，图片文件当前不能超过 `4 MB`。手动封面会优先于平台元数据封面。

## 原创、转载与授权

如果投稿人是视频作者，应确保当前 NexusMC 账号或组织有权维护该视频条目。

如果投稿他人视频，应在简介中写明：

-   原作者或发布账号。
-   原始平台和来源链接。
-   投稿用途，例如教程推荐、社区资料整理或活动记录。
-   转载、嵌入或二次发布所依据的授权。

不得删除原作者署名、把他人视频写成原创，或通过更换标题和封面制造错误归属。

CAUTION

平台允许公开播放不代表允许冒充原创、剪辑搬运或商业再发布。来源和授权存在争议时，审核可能拒绝或下架投稿。

## 内容边界

适合投稿的视频通常包括：

-   Minecraft 教程、开发、建筑、红石和玩法内容。
-   服务器、模组、插件、资源包或地图介绍。
-   社区活动、赛事、访谈和公开记录。
-   与 NexusMC 已有资源、帖子或找服玩服务器直接相关的视频。

不适合投稿：

-   与 Minecraft 或社区主题无关的泛娱乐内容。
-   纯广告、抽奖引流或无法验证的宣传片。
-   包含恶意程序、账号交易、欺诈或绕过安全机制的教程。
-   未经许可泄露服务器后台、私人聊天或个人信息的视频。
-   已删除、仅自己可见或反复失效的来源。

## 可见性与访问模式

视频投稿支持公开、部分可见和私密等可见性，也支持无额外限制、密码、回复后可见或登录后可见等访问模式。

选择时注意：

-   面向社区推荐的公开视频通常使用 `public + none`。
-   `partial` 必须提供允许查看的用户列表。
-   `password` 必须设置 4 到 64 字符的访问密码。
-   不要用回复、登录或密码限制隐藏视频来源、作者和版权信息。
-   站内访问限制不会改变外部视频平台自己的可见性。

## 以组织身份投稿

前台允许有相应组织发布权限的成员以组织名义投稿。使用组织身份前应确认：

-   视频确实代表该组织或与组织项目有关。
-   当前账号具有组织视频发布权限。
-   标题、简介和来源不会让用户误认为是其他主体发布。

个人 API Token 当前不支持指定 `organizationId`，脚本投稿应归属于 Token 用户本人。

## 首发与后续更新

视频当前没有草稿状态。创建成功后会直接进入 `pending`，因此提交前应一次检查完整。

以下变化会使视频重新进入审核：

-   更换来源链接。
-   修改标题、简介或分区。
-   修改封面或标签。
-   更改组织归属、可见性或访问模式。

更换来源链接时，系统会重新解析平台、视频 ID 和嵌入地址，也可能重新读取标题和封面。不要用编辑功能把已审核视频替换成无关内容。

来源视频删除、转为私密或发生重大内容变化后，应及时更新或停止展示对应投稿。

## 审核重点

审核人员通常会检查：

1.  来源是否属于支持平台并能稳定打开。
2.  标题、简介、分区、标签和封面是否与视频一致。
3.  视频是否与 Minecraft 或 NexusMC 社区有关。
4.  投稿人、原作者和组织归属是否清楚。
5.  是否存在搬运、误导、欺诈、恶意下载或隐私风险。
6.  可见性和访问模式是否合理。

## 首发前检查清单

展开检查清单

-   来源链接是否为受支持平台的视频详情页。
-   视频能否在普通访问状态下播放。
-   标题是否准确且没有标题党。
-   简介是否说明内容、适用版本和作者来源。
-   分区和标签是否与主题一致。
-   封面是否清晰、真实且没有敏感信息。
-   原创、转载和授权关系是否写清楚。
-   组织身份是否使用正确。
-   可见性和访问模式是否符合实际用途。
-   是否确认提交后会立即进入审核且没有草稿。
