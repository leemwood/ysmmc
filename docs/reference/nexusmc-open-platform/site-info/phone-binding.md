# 手机号绑定

说明 Gee ID 手机号绑定流程、Gee ID 前置条件、地区限制，以及绑定与更新手机号时会遇到的常见情况。

## 这是什么

手机号绑定分区用于通过 Gee ID 的短信验证机制绑定或更新当前账号手机号。

当前入口在：

```
/settings?tab=phone
```

## 当前流程的核心特点

这不是一个“直接填手机号就结束”的普通表单。按当前实现，它依赖 Gee ID 作为中间层。

也就是说，手机号绑定前通常要先满足：

1.  站点启用了 Gee ID 手机绑定功能
2.  当前账号具备可用于 Gee ID 的邮箱
3.  当前账号已经绑定或补建了 Gee ID
4.  当前账号和当前访问地区满足大陆手机号绑定条件

## 页面结构

当前手机号绑定页主要分成三段：

| 区块 | 作用 |
| --- | --- |
| Gee ID 账号确认 | 先开通 Gee ID，或绑定已有 Gee ID |
| 当前绑定状态 | 显示当前手机号是否已绑定 |
| 手机号验证表单 | 发送验证码并确认绑定 |

## Gee ID 前置条件

按当前前台逻辑，先要处理 Gee ID：

-   如果你还没有 Gee ID，可以点击“开通 Gee ID”
-   如果你已有 Gee ID，可以先去账号绑定区绑定已有 Gee ID

当前页面也支持一种补救路径：对于存量账号，如果还没有 Gee ID，系统可能会在首次发送验证码时尝试自动补建。

## 标准绑定流程

1.  进入“设置 -> 手机号绑定”。
2.  先完成 Gee ID 开通或绑定。
3.  输入中国大陆手机号。
4.  点击“发送验证码”。
5.  收到短信后输入验证码。
6.  点击“确认绑定”。

如果当前账号已经绑定过手机号，页面会显示“修改手机号”入口，而不是纯粹的首次绑定状态。

## 当前支持哪类手机号

按当前前台输入和校验逻辑，当前这里面向的是中国大陆手机号，默认按 `+86` 体系处理。

因此你在页面里一般需要输入的是 11 位大陆手机号。

## 地区和账号限制

手机号绑定当前不只是看你填的号码，还会检查：

-   账号注册地区是否支持 Gee ID 大陆手机号绑定
-   当前访问地区是否支持 Gee ID 中国大陆手机号绑定

如果这两层中有任意一层不满足，系统会直接拒绝继续绑定。

## 同步和更新是什么意思

当前实现里，Gee ID 与本地账号之间有同步逻辑。

这意味着：

-   如果 Gee ID 那边已经绑定过手机号，系统可能会直接同步本地状态
-   如果你原本已经有手机号，再重新绑定，返回文案更可能是“手机号更新成功”

## 什么时候会看见“Gee ID 已就绪”

这表示当前账号的 Gee ID 前置条件已经满足，接下来可以直接走短信验证码流程，不需要再重复做 Gee ID 绑定准备。

## 和安全前置条件的关系

手机号绑定除了账号资料用途外，也可能与某些前置门槛相关。

例如当前站点可以按动作要求：

-   在中国大陆访问时，先绑定手机号才能继续发帖、评论或修改资料

相关说明见 [安全前置条件](/docs/site-info/security-prerequisites/)。

## 常见失败原因

展开查看手机号绑定常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 页面提示未启用 | 站点没有开启 Gee ID 手机绑定 | 以当前站点配置为准 |
| 发送验证码失败 | 手机号格式不对，或 Gee ID 前置条件未满足 | 先确认 Gee ID 和手机号格式 |
| 提示当前访问地区不支持 | 当前访问地区未命中允许条件 | 在允许地区访问或联系管理员确认策略 |
| 提示当前账号注册地区不支持 | 账号注册地区不满足绑定条件 | 这不是单纯刷新页面能解决的问题 |
| 提示手机号已被其他账号绑定 | 该号码已被别的账号占用 | 更换号码或处理原账号绑定 |
| 当前账号没有可用于 Gee ID 的邮箱 | 账号邮箱仍不可用于 Gee ID | 先补齐邮箱或完成 GeeID OAuth 绑定 |

## 疑难解答

### 我已经绑定过手机号，还能改吗？

可以。当前页面有“修改手机号”入口，底层走的是更新绑定流程。

### 为什么这个功能和普通手机号绑定不一样，还要管 Gee ID？

因为按当前站点实现，手机号验证链路就是通过 Gee ID 提供的短信绑定能力来完成的。
