# 推广码

说明推广链接的解锁条件、使用方式、奖励逻辑和推广记录页面会展示什么。

## 这是什么

推广码功能会为每个用户生成一个专属注册链接。新用户通过这个链接完成注册后，推广人可以按当前站点设置获得奖励。

当前用户侧入口在：

```
/settings?tab=referral
```

页面中会显示：

-   你的推广码
-   你的推广链接
-   成功推广人数
-   累计获得奖励
-   推广明细

## 先决条件

当前要正常使用推广码功能，至少要满足两层条件：

1.  站点已开启推广功能
2.  你的账号已经解锁 `use_referral` 能力

按当前默认实现，`use_referral` 由入站考试负责解锁。

IMPORTANT

如果你还没有参加过入站考试，即使设置页里已经有“推广链接”分区，也可能无法正常加载推广数据。

## 推广链接长什么样

系统会为你生成类似下面的地址：

```
/register?ref=你的推广码
```

用户通过这个链接进入注册流程后，系统会尝试把这次注册与推广人关联起来。

## 奖励什么时候发放

按当前实现，奖励是在“被推广用户完成注册”时结算的，不需要等对方先发帖、签到或完成额外任务。

奖励数值来自站点当前设置项 `referral-register-reward`。因此不同部署或不同阶段，页面看到的奖励值可能不同。

如果站点没有启用积分系统，或者当前奖励值被设为 `0`，那么仍然可以记录邀请关系，但不一定会发放正数奖励。

## 页面上的数据怎么理解

| 字段 | 含义 |
| --- | --- |
| 推广码 | 你的唯一推广标识 |
| 成功推广 | 已通过你的推广关系完成注册的用户数 |
| 累计获得积分 | 你因推广奖励累计拿到的奖励值 |
| 推广明细 | 被推广用户、注册时间、奖励数值和奖励发放时间 |

推广明细默认会分页显示，当前前台支持继续加载更多记录。

## 标准流程

1.  先完成入站考试，确保推广能力已经解锁。
2.  打开“设置 -> 推广链接”。
3.  复制系统生成的注册链接。
4.  把链接分享给准备注册的新用户。
5.  对方完成注册后，系统记录推广关系并按当前设置尝试发放奖励。
6.  你可以回到设置页查看推广人数和奖励明细。

## 功能边界

当前文档只描述用户侧已开放能力。按当前实现，这个功能有几个边界：

-   奖励数值由后台设置决定，不是固定常量
-   奖励明细主要用于查看自己的推广记录，不是公开排行榜
-   如果站点关闭推广功能，设置页会显示“当前暂未开启推广码功能”
-   推广功能不是后台代理操作，不会让你获得管理权限或替他人操作账号

## 常见失败原因

展开查看推广码常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 设置页显示暂未开启 | 站点关闭了推广功能 | 等站点重新开放 |
| 推广区加载失败 | 还没有解锁 `use_referral` 能力 | 先参加入站考试 |
| 复制链接后别人注册了但没有奖励 | 奖励值为 `0`、积分系统未生效，或邀请未成功关联 | 检查注册链接是否正确、稍后再看明细 |
| 推广人数增加了但累计奖励没变 | 当前奖励值可能为 `0`，或该条推广记录尚未生成奖励流水 | 查看推广明细和奖励发放时间 |
| 看不到很早以前的记录 | 当前列表按分页加载 | 继续点击“加载更多” |

## 疑难解答

### 推广码是我自己设置的吗？

不是。按当前实现，系统会为用户生成并维护推广码。

### 只有新用户才算推广成功吗？

是。推广链接用于注册链路，不适用于已经注册完成的老账号。

### 我能看到被推广人的哪些信息？

当前前台推广明细主要展示用户名、UID、slug、注册时间、奖励数值和奖励发放时间。

### 推广功能和任务系统是同一个东西吗？

不是。它们都可能由入站考试解锁，但属于不同功能。
