# 考试中心

说明入站考试、开发者考试、能力解锁、奖励结算和考试中心页面的使用方式。

## 这是什么

考试中心用于管理站内的能力解锁型考试。当前用户侧入口是：

```
/user/me/exams
```

这里会显示：

-   你已经解锁的考试能力
-   当前开放的考试
-   每个考试最近一次作答结果
-   奖励结算状态和历史最佳分

NOTE

考试中心是用户功能页，不是后台题库管理页。管理员维护题库和考试配置时，需要在后台操作。

## 当前有哪些考试

当前默认有两类考试：

| 考试 | 作用 | 当前默认要求 |
| --- | --- | --- |
| 入站考试 | 解锁基础互动能力，例如投币、评分、推广和任务 | 任何一次成功参与后即可解锁对应基础能力 |
| 开发者考试 | 解锁创作者发布资格的考试步骤，以及个人 API Token 创建和管理能力 | 分数达到 `80` 分及以上 |

IMPORTANT

“解锁能力”和“奖励结算”不是一回事。入站考试的基础能力按当前实现以“已参与”作为触发条件；开发者考试的 API Token 能力则要求达到目标分数。

## 当前会解锁哪些能力

考试中心当前会显示已解锁能力标签。默认能力含义如下：

| 能力标识 | 用户可做什么 |
| --- | --- |
| `use_point_tip` | 可以对内容进行投币支持 |
| `use_resource_rating` | 可以对资源和找服玩服务器进行评分 |
| `use_referral` | 可以使用推广链接邀请新用户 |
| `use_tasks` | 可以使用任务系统 |
| `create_api_token` | 可以创建和管理个人 API Token |
| `publish_content` | 可以进入创作者协议确认步骤，完成后正式投稿 |

如果你在某个功能页看到“先完成对应考试”的提示，通常就是因为这个能力还没有被解锁。

## 标准流程

1.  进入考试中心页面。
2.  查看“能力解锁概览”和“可参加考试”。
3.  选择一场已发布且已启用的考试开始作答。
4.  系统从该考试独立题库中随机抽题，并可能打乱题目或选项顺序。
5.  提交后立即看到本次得分、是否达标、历史最佳分和奖励状态。
6.  若该考试对应能力已满足解锁条件，相关功能页会随之开放。

## 页面上会看到什么

考试中心当前主要分成三块：

| 区块 | 作用 |
| --- | --- |
| 能力解锁概览 | 显示已解锁能力数量、能力标签和已参与考试数 |
| 可参加考试 | 显示考试标题、分类、及格分、题量、奖励状态和最近作答时间 |
| 最近一次结果 | 显示最新成绩、答对题数、是否通过、历史最佳和本次解锁能力 |

如果站点当前没有开放任何考试，页面会显示“当前没有开放考试”而不是报错。

## 入站考试

入站考试主要用于帮助用户理解站内互动边界，并逐步开放基础功能。

当前默认特点：

-   分类为 `onboarding`
-   及格分默认 `60`
-   支持单选、多选、判断三类题
-   奖励期内允许重复参加
-   奖励按奖励期内的更高成绩结算

按当前默认配置，入站考试的奖励期还有两个关键参数：

| 参数 | 当前默认值 | 含义 |
| --- | --- | --- |
| `maxRewardAttempts` | `4` | 奖励期内最多按前 4 次尝试参与奖励结算 |
| `rewardLockScore` | `80` | 达到该分数后，奖励状态可被锁定 |

TIP

如果第一次分数不理想，奖励期内可以继续参加，争取拿到更高的结算结果。

## 开发者考试

开发者考试用于控制创作者发布资格和个人 API Token 的开放门槛。

当前默认特点：

-   分类为 `developer`
-   及格分默认 `80`
-   达到目标分数后，解锁 `create_api_token` 和 `publish_content`
-   `create_api_token` 开放个人 API Token 的查看、创建、编辑和撤销能力
-   `publish_content` 允许进入创作者协议确认步骤；确认当前版本协议后才具备完整投稿资格
-   本身默认不承担积分奖励结算

如果你在“设置 -> API Token”里看到未开放提示，通常说明开发者考试还没有达到要求分数。

如果投稿页提示需要确认成为创作者，说明考试已经达标，但还没有确认当前版本的创作者协议。完整流程见 [创作者开通与协议确认](/docs/site-info/creator-onboarding/)。

## 奖励和锁定是什么意思

考试中心里的“奖励状态”是独立概念，不等同于是否达标。

当前页面会展示：

-   是否还处在奖励期
-   已累计结算的奖励值
-   是否已经锁定
-   奖励锁定分
-   奖励期已用次数

一般可以这样理解：

| 状态 | 含义 |
| --- | --- |
| 可继续刷新 | 还可以继续参加，争取更好的奖励期成绩 |
| 已锁定 | 奖励结算已固定，后续再参加通常不会继续增加这部分奖励 |

## 常见失败原因

展开查看考试相关常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 页面显示“当前没有开放考试” | 当前没有已发布且启用的考试 | 等管理员开放考试 |
| 点击开始考试失败 | 考试已停用、已下线或 key 无效 | 刷新页面后重试 |
| 提交考试失败 | 作答数据缺失或考试记录已失效 | 重新开始一次新的作答 |
| API Token 区域仍未开放 | 开发者考试分数未达到要求 | 继续参加开发者考试并达到目标分数 |
| 投稿页仍然不能使用 | 尚未确认当前版本的创作者协议 | 前往创作者中心完成确认 |
| 推广、任务、投币等功能仍不可用 | 还没有完成入站考试对应能力解锁 | 先参加入站考试 |

## 疑难解答

### 入站考试一定要及格才会解锁基础能力吗？

按当前默认实现，入站考试对应的基础能力使用“已参与”作为触发条件，而不是“必须及格”。但奖励结算和页面显示成绩仍然独立存在。

### 开发者考试通过后会直接变成管理员吗？

不会。开发者考试当前用于解锁个人 API Token 能力和创作者发布流程，不会授予后台权限。

### 开发者考试通过后可以立即投稿吗？

还需要确认当前版本的创作者协议。考试负责解锁能力，协议负责记录发布责任边界。

### 每次考试题目都一样吗？

不一定。当前实现支持独立题库、随机抽题，以及题目或选项顺序打乱。

### 奖励锁定后还能继续参加吗？

通常仍然可以继续打开考试，但奖励状态已经锁定时，不应再期待继续追加同一阶段奖励。
