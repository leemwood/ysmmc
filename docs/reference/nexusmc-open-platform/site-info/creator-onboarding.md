# 创作者开通与协议确认

说明开发者考试、创作者协议、发布资格和个人 API Token 之间的关系，以及协议版本更新后的处理方式。

## 这是什么

NexusMC 使用“开发者考试 + 创作者协议”控制内容发布资格。用户完成考试后，还需要阅读并确认当前版本的创作者协议，才能正式提交帖子、资源、找服玩服务器和视频。

用户侧入口：

```
/creator/about#creator-agreement
```

IMPORTANT

站内“确认成为创作者”是对当前版本创作者协议的确认记录，不是实名认证、电子签名或 NexusMC 个人认证。需要可信身份标识时，请另行申请 [NexusMC 个人认证或组织认证](/docs/site-info/account-verification/)。

## 四个概念不要混淆

| 概念 | 解决什么问题 | 会不会直接开放投稿 |
| --- | --- | --- |
| 开发者考试 | 确认用户理解发布规范、授权边界、接口安全和平台规则 | 只完成第一步，还需要确认创作者协议 |
| 创作者协议 | 记录用户对当前协议版本的同意时间和责任承诺 | 考试已达标时，确认后开放正式投稿 |
| 个人 API Token | 为自己的脚本和自动化工具提供接口凭据 | Token scope 不能替代创作者发布资格 |
| 个人/组织认证 | 在用户或组织主页展示可信身份标识 | 不授予投稿、API 或后台权限 |

开发者考试默认同时解锁两个能力：

-   `publish_content`：进入创作者协议确认步骤。
-   `create_api_token`：在设置页创建和管理个人 API Token。

这两个能力后续走不同流程。创建 Token 不要求先确认创作者协议；使用 Token 正式投稿时，账号仍需具备完整创作者发布资格。

## 开通流程

1.  登录状态正常的 NexusMC 账号。
2.  前往 [考试中心](/docs/site-info/exam-center/) 参加开发者考试。
3.  达到当前发布能力要求。默认分数门槛为 `80` 分。
4.  打开创作者中心，阅读页面展示的当前协议内容和版本。
5.  点击“确认成为创作者”。
6.  系统记录确认时间与协议版本，并开放创作者工作台和正式投稿能力。

管理员、总版主和各业务版主等管理角色可以跳过考试门槛，但仍需要确认当前版本的创作者协议。

## 状态说明

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| `guest` | 当前未登录 | 登录后重新打开创作者中心 |
| `exam_required` | 尚未解锁 `publish_content` | 参加开发者考试并达到要求 |
| `agreement_required` | 考试已达标，但当前协议尚未确认 | 阅读并确认当前版本协议 |
| `active` | 考试和协议均已完成 | 进入创作者工作台或投稿页 |
| `restricted` | 账号当前不可开通创作者功能 | 先处理账号状态或联系管理组 |

前台和个人 API 在资格不足时，可能返回以下错误代码：

| 错误代码 | 原因 | 处理方式 |
| --- | --- | --- |
| `CREATOR_EXAM_REQUIRED` | 开发者考试尚未达到发布门槛 | 前往考试中心完成考试 |
| `CREATOR_AGREEMENT_REQUIRED` | 尚未确认当前版本协议 | 打开创作者中心完成确认 |

## 协议版本更新

站点会同时保存：

-   用户确认协议的时间。
-   用户已确认的协议版本。
-   站点当前要求的协议版本。

只有“已确认版本”和“当前版本”一致时，协议状态才有效。站点更新协议版本后，旧确认记录不会丢失，但用户需要阅读新内容并再次确认，才能恢复正式投稿资格。

NOTE

协议内容和版本由站点后台维护。请以确认页面当时展示的正文和版本号为准，不要依赖截图或旧公告。

## 开通后能做什么

完整开通后，账号可以进入创作者工作台，并正式提交：

-   帖子
-   资源与资源版本
-   找服玩服务器
-   视频

开通创作者功能不代表投稿会直接公开。正文、分类、授权、外链、安全设置、手机号、发布频率和内容审核等规则仍然有效。

## 常见问题

### 通过开发者考试后，为什么仍然不能投稿？

考试只完成第一步。请打开创作者中心，确认当前版本的创作者协议。

### 已经确认过协议，为什么又要求确认？

通常是站点更新了协议版本。旧版本的确认时间仍会保留，但需要再次确认当前版本。

### 创建个人 API Token 也必须确认协议吗？

创建和管理 Token 本身只检查 `create_api_token` 能力。使用 Token 正式发布内容时，还会检查完整创作者资格。

### 个人认证通过后，可以跳过考试或协议吗？

不能。认证标识和发布资格是两套独立机制。

### 确认协议后会获得管理员权限吗？

不会。创作者资格只影响内容发布入口，不授予审核、用户管理或后台配置权限。
