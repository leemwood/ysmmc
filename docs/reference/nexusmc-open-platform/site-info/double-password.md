# 双层密码（二次密码）

说明双层密码的用途、开启条件、设置与删除流程，以及它和账号密码、2FA、通行密钥的区别。

## 这是什么

双层密码也可以理解为“二次密码”。它是账号密码体系下的一组额外口令，用于在部分高安全操作前再次确认身份。

当前入口在：

```
/settings?tab=double-password
```

设置页左侧菜单中显示为：

```
设置 -> 双层密码
```

## 它解决什么问题

账号登录成功后，系统仍然可能需要确认“当前操作确实是本人发起”。双层密码就是其中一种确认方式。

它通常用于：

-   删除账号、修改关键信息等高风险操作
-   部分正式发布、回复、评论或评分前的安全要求
-   在没有绑定 2FA 或通行密钥时，作为账号密码体系下的额外确认手段

NOTE

双层密码不是登录密码的替代品，也不是无密码登录能力。它更像是在登录密码之外，再准备一把只用于敏感操作确认的口令。

## 开启条件

当前实现要求账号必须先设置普通账号密码，才能启用双层密码。

| 账号状态 | 是否能启用双层密码 |
| --- | --- |
| 已设置账号密码 | 可以启用 |
| 仅使用通行密钥登录，没有账号密码 | 不能启用 |
| 还没有任何账号密码 | 需要先设置账号密码 |

如果账号处于无密码模式，页面会提示不能启用双层密码。原因是双层密码属于账号密码体系的增强，安全等级低于通行密钥，不应在没有账号密码的情况下单独启用。

## 设置流程

1.  进入 `设置 -> 双层密码`。
2.  输入新的双层密码。
3.  再输入一次确认密码。
4.  提交设置。

当前要求：

-   双层密码至少 `6` 个字符
-   最长 `128` 个字符
-   两次输入必须一致

建议不要把双层密码设成和账号登录密码完全一样。否则它提供的“二次确认”价值会明显降低。

## 修改与删除

已设置双层密码后，页面会显示管理选项：

| 操作 | 需要什么 |
| --- | --- |
| 修改双层密码 | 输入当前双层密码，再输入新双层密码 |
| 删除双层密码 | 输入当前双层密码确认删除 |

删除后，后续需要双层密码确认的操作将不能再使用这一路径。若站点要求先完成安全绑定，你可能需要改为绑定 2FA 或通行密钥，或重新设置双层密码。

## 和 2FA、通行密钥的区别

| 能力 | 主要用途 | 安全层级 |
| --- | --- | --- |
| 双层密码 | 用额外口令确认高风险操作 | 账号密码体系下的增强 |
| 二步验证（2FA） | 使用验证码应用完成二次验证 | 独立于登录密码，更适合安全绑定 |
| 通行密钥 | 使用设备、生物识别或系统凭据完成认证 | 更适合无密码登录和强确认 |

如果可以选择，优先绑定通行密钥或 2FA。双层密码适合作为兼容性更强的备用安全方式。

## 和安全前置条件的关系

站点某些操作会要求用户先具备至少一种安全绑定。当前可用路径包括：

-   二步验证（2FA）
-   通行密钥
-   双层密码

如果账号只设置了双层密码，没有绑定 2FA 或通行密钥，那么部分高风险操作在继续前可能会要求你输入双层密码完成确认。

详情见 [安全前置条件](/docs/site-info/security-prerequisites/)。

## 常见失败原因

展开查看双层密码常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 页面提示不能启用 | 当前账号没有普通账号密码 | 先到 [密码设置与无密码模式](/docs/site-info/password-settings/) 设置账号密码 |
| 两次输入不一致 | 新双层密码和确认密码不同 | 重新输入 |
| 设置失败 | 双层密码长度不足或超过限制 | 使用 6 到 128 个字符 |
| 修改失败 | 当前双层密码不正确 | 确认输入的是双层密码，不是账号登录密码 |
| 删除失败 | 当前双层密码不正确 | 重新输入当前双层密码 |
| 无密码模式下无法设置 | 双层密码依赖账号密码体系 | 继续使用通行密钥，或先恢复账号密码 |

## 疑难解答

### 双层密码是不是登录密码？

不是。登录密码用于登录账号；双层密码用于登录后对高风险操作做额外确认。

### 可以和登录密码一样吗？

系统不会建议这样做。双层密码的意义在于额外确认，如果和登录密码完全相同，安全收益会变低。

### 只设置双层密码，不绑定 2FA 或通行密钥可以吗？

部分场景可以满足安全绑定要求，但 2FA 和通行密钥通常更强。长期使用账号时，建议至少再绑定一种 2FA 或通行密钥。
