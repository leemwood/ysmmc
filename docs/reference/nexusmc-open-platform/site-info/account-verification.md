# NexusMC 个人认证与组织认证

说明个人认证、企业认证和机构认证的申请条件、GeeID 前置要求、材料、审核状态与公开展示范围。

## 这是什么

NexusMC 认证中心用于核验个人创作者、开发者、社区成员、企业或机构主体，并在对应用户主页或组织主页展示认证标识。

申请入口：

```
/offices
```

申请记录查询：

```
/offices/query
```

IMPORTANT

认证用于说明“这个账号或组织的身份已经过核验”，不等同于站点角色、创作者发布资格或个人 API 权限。认证通过后不会自动获得投稿、审核或后台权限。

## 认证方向

### 个人认证

| 申请方向 | 适合谁 | 当前主要条件 |
| --- | --- | --- |
| 知名开发者认证 | 在站内持续发布内容并具有稳定关注者的开发者 | 至少 3 篇已审核内容、至少 100 位站内关注者、无有效违规或账号限制 |
| 身份认证 | 在站外具有公开职业身份或公众影响力的运营者 | 已绑定手机号、GeeID 个人认证通过、站外账号至少 10,000 粉丝并能证明账号归属 |
| 社区名人认证 | 在 Minecraft 社区持续贡献并具有公共影响力的成员 | 已绑定手机号、GeeID 个人认证通过，并选择当前开放的认证分类 |

知名开发者认证会直接读取站内已审核资源、帖子、视频数量和关注者数量，不要求填写额外申请表，但提交后仍会进入人工复核。

### 组织认证

| 申请方向 | 适合谁 | 当前主要条件 |
| --- | --- | --- |
| 企业认证 | 持有营业执照、统一社会信用代码的企业主体 | 已绑定手机号、GeeID 企业认证通过、企业资料和申请公函完整 |
| 机构认证 | 事业单位、媒体、高校组织、团队及其他可核验机构 | 已绑定手机号、GeeID 企业认证通过、主体证明和申请公函完整 |

企业认证和机构认证都可以选择：

-   认证当前登录的个人账号。
-   认证由当前账号创建并持有的站内组织。

选择组织账号时，申请人必须是组织所有者。组织管理员或普通成员不能代替所有者提交该组织的认证申请。

## GeeID 与 NexusMC 认证的关系

部分认证会在提交时读取当前账号绑定的 GeeID 实名状态：

| NexusMC 申请方向 | 要求的 GeeID 类型 |
| --- | --- |
| 身份认证、社区名人认证 | `PERSONAL` 个人认证 |
| 企业认证、机构认证 | `ENTERPRISE` 企业认证 |
| 知名开发者认证 | 当前不要求 GeeID 实名状态 |

GeeID 必须已经绑定，`realname` 为真、认证状态为通过，并且认证类型与申请方向一致。只绑定 GeeID 但没有完成对应实名认证，仍然不能提交。

账号绑定入口：

```
/settings?tab=oauth
```

## 申请流程

1.  登录后进入认证中心并选择认证方向。
2.  系统检查手机号、GeeID、站内数据、账号状态和可用认证分类。
3.  满足条件后进入申请表。
4.  选择认证当前个人账号，或选择自己持有的组织账号。
5.  填写联系信息、认证称号和主体资料，上传证明文件。
6.  提交后保存申请编号，并进入“审核中”。
7.  在申请查询页查看结果、审核意见，或在审核期间撤回申请。

提交申请后，账号条件和 GeeID 状态会再次核验。条件检查页通过，不代表稍后提交一定成功。

## 主要申请材料

### 身份认证

-   认证昵称和身份/职位
-   运营者手机号与联系邮箱
-   站外平台和账号链接
-   站外粉丝量
-   站外账号权利主体
-   后台截图、账号声明或其他账号归属证明

### 社区名人认证

-   认证昵称和社区身份
-   联系手机号与邮箱
-   当前开放的认证分类
-   可选的社区贡献或影响力补充材料

### 企业或机构认证

-   认证称号
-   运营者身份证姓名、手机号和联系邮箱
-   企业或机构主体全称
-   统一社会信用代码
-   营业执照、事业单位证明或其他主体文件
-   认证申请公函
-   企业认证还需要按证照填写注册资金

**NexusMC 企业实名认证授权书模板** 申请企业认证时，请下载并按模板填写，再根据申请页面要求随认证材料一并上传。 Word 文档 · DOCX

[下载模板](/download/NexusMC企业实名认证授权书模板.docx)

单个上传文件不能超过 `20 MB`。证明文件应清晰、完整，主体名称、联系方式和申请称号之间应保持一致。

## 审核状态

| 状态 | 含义 | 用户能做什么 |
| --- | --- | --- |
| `pending` | 申请正在人工审核 | 查看进度，或撤回申请 |
| `approved` | 申请已通过，对应认证已授予 | 查看用户或组织主页上的认证信息 |
| `rejected` | 申请未通过 | 阅读审核意见，修正后重新申请 |
| `cancelled` | 申请人已撤回 | 重新准备材料后再次提交 |

只有 `pending` 状态的申请可以撤回。审核中的同类型申请不能重复提交。

## 认证如何展示

审核通过后，系统会为目标对象授予认证：

-   知名开发者、身份认证、社区名人认证统一归入“个人认证”。
-   企业认证、机构认证统一归入“机构认证”。

同一个用户或组织不能重复拥有同一类有效认证。前台会展示有效且可见的认证标识、认证名称和审核授予的说明；认证过期、被撤销、被隐藏或类型停用后不再作为有效标识展示。

NOTE

申请表中的身份证明、联系方式、证照和上传文件仅用于认证审核。前台不会公开整份申请材料。

## 常见失败原因

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 当前无法继续申请 | 手机号、站内数据或账号状态未满足要求 | 按条件检查页逐项处理 |
| 提示先绑定 GeeID | 当前账号没有 GeeID OAuth 绑定 | 到账号绑定页完成绑定 |
| GeeID 类型不匹配 | 个人申请使用了企业认证，或组织申请使用了个人认证 | 在 GeeID 完成对应类型认证后重试 |
| 无法选择组织 | 当前账号没有自己创建并持有的组织 | 先创建组织，或改为认证个人账号 |
| 认证分类不可用 | 后台尚未配置或已停用对应分类 | 稍后重试或联系管理组 |
| 提示已经拥有认证 | 当前目标已有对应“个人认证”或“机构认证” | 无需重复申请 |
| 提示已有申请正在审核 | 同一目标存在同类型 `pending` 申请 | 等待审核，或先撤回原申请 |
| 文件上传失败 | 单文件超过 20 MB 或上传服务异常 | 压缩文件或稍后重试 |
| 提交过于频繁 | 一小时内提交次数达到限制 | 等待限流窗口结束后再试 |

## 常见问题

### 成为创作者后会自动获得个人认证吗？

不会。创作者开通和身份认证需要分别完成。

### 企业认证只能显示在组织主页吗？

不是。企业认证和机构认证可以授予当前个人账号，也可以授予申请人持有的站内组织。提交时应先确认认证对象。

### 组织管理员可以申请组织认证吗？

当前不可以。只有组织所有者能为自己创建并持有的组织提交认证。

### 被拒绝后可以重新申请吗？

可以。根据审核意见修正条件或材料后重新提交即可。

### 认证通过后会绕过内容审核吗？

不会。认证标识不会改变投稿审核、内容安全、发布频率或账号安全要求。
