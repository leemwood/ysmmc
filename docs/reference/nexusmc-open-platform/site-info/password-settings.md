# 密码设置与无密码模式

说明设置密码、修改密码、删除密码、忘记密码，以及无密码模式当前的开启条件和影响。

## 这是什么

密码设置分区负责处理账号的密码相关能力，包括：

-   首次设置密码
-   修改已有密码
-   删除密码进入无密码模式

当前入口在：

```
/settings?tab=password
```

## 页面会根据账号状态切换

当前设置页不是所有人都看到同一套表单，而是按账号状态切换：

| 账号状态 | 页面表现 |
| --- | --- |
| 当前没有密码 | 显示“设置密码”表单 |
| 当前已有密码 | 显示“修改密码”表单 |
| 当前已有密码且已绑定通行密钥 | 额外显示“删除密码 / 无密码模式”区域 |

## 设置密码

如果你的账号当前没有密码，页面会提示你目前通过通行密钥或邮箱验证码登录。

这时可以直接：

1.  输入新密码
2.  再输入一次确认密码
3.  提交设置

当前前台要求密码至少 `6` 个字符。

## 修改密码

如果你的账号已经设置过密码，修改流程会要求：

1.  输入当前密码
2.  输入新密码
3.  再确认一次新密码

按当前实现：

-   新密码长度至少 6 个字符
-   两次输入必须一致
-   某些站点配置下还可能要求先完成人机验证

修改成功后，前台会提示你重新登录。

## 忘记当前密码

修改密码表单旁边当前提供了“忘记当前密码？”入口，会走密码找回流程，而不是直接在当前设置页里绕过旧密码。

所以：

-   记得当前密码，用“修改密码”
-   不记得当前密码，用“忘记密码”

## 无密码模式

当前设置页支持一种“无密码模式”。

### 含义

无密码模式不是把账号变成“不需要认证”，而是把密码登录移除，后续改为依赖通行密钥登录。

### 开启条件

按当前实现，只有同时满足这两个条件时，才会显示“删除密码”入口：

1.  当前账号已经有密码
2.  当前账号至少绑定了一把通行密钥

### 删除密码后会发生什么

删除后：

-   当前密码会被移除
-   后续需要通过通行密钥登录
-   如果之后想恢复密码登录，可以再回来重新设置密码

IMPORTANT

无密码模式的前提是你真的有一条稳定可用的通行密钥登录路径。否则删掉密码之后，恢复账号会麻烦很多。

## 和通行密钥的关系

无密码模式本质上依赖通行密钥，所以这两块文档最好一起看：

-   [通行密钥](/docs/site-info/passkeys/)
-   [二步验证（2FA）](/docs/site-info/two-factor-auth/)

## 和双层密码的关系

双层密码（二次密码）依赖普通账号密码。只有账号已经设置了登录密码时，才可以启用双层密码。

如果账号进入无密码模式，只保留通行密钥登录，双层密码将不能新启用或修改。详情见 [双层密码（二次密码）](/docs/site-info/double-password/)。

## 常见失败原因

展开查看密码设置常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 设置密码失败 | 已经有密码，当前账号不属于“首次设置密码”状态 | 改走修改密码流程 |
| 修改密码失败 | 当前密码错误，或新密码不满足要求 | 检查当前密码与新密码长度 |
| 两次输入不一致 | 新密码和确认密码不同 | 重新输入 |
| 删除密码失败 | 当前还没有通行密钥 | 先绑定至少一把通行密钥 |
| 删除密码后不能密码登录 | 已进入无密码模式 | 使用通行密钥登录 |

## 疑难解答

### 没有密码的账号就不安全吗？

不一定。当前设计里，无密码模式是建立在通行密钥可用的前提上，它不是“无认证”，只是换了一种认证方式。

### 删除密码后还可以再设回来吗？

可以。后续仍然可以回到密码设置页重新设置密码。
