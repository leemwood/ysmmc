# 主站常见问题

汇总站点账号、投稿、审核、私信、通知、搜索和安全相关的常见问题。

## 账号与登录

忘记密码怎么办

如果账号绑定了邮箱，可以通过重置密码流程找回。若启用了两步验证或通行密钥，请按页面提示完成额外验证。

如果邮箱不可用，建议联系管理员，并准备能证明账号归属的信息。

详情见 [密码设置与无密码模式](/docs/site-info/password-settings/) 和 [邮箱设置](/docs/site-info/email-settings/)。

可以修改用户名吗

是否允许修改用户名取决于当前站点配置。若页面没有提供修改入口，说明该能力可能暂未开放，或需要管理员协助。

为什么需要绑定邮箱或手机号

绑定信息用于账号找回、安全验证、通知发送和风控判断。不同登录方式下，可用的绑定项可能不同。

如果是第三方登录账号，建议尽早补齐可用邮箱；如果当前访问地区命中大陆手机号策略，再按页面提示补手机号。

详情见 [邮箱设置](/docs/site-info/email-settings/) 和 [手机号绑定](/docs/site-info/phone-binding/)。

为什么系统提示我要先绑定 2FA、通行密钥或双层密码

这是增强认证前置条件。部分正式发布、高风险操作或敏感设置会要求账号至少绑定一种增强认证方式。

先看 [安全前置条件](/docs/site-info/security-prerequisites/) ，再到设置页里的 [二步验证（2FA）](/docs/site-info/two-factor-auth/)、[通行密钥](/docs/site-info/passkeys/) 或 [双层密码（二次密码）](/docs/site-info/double-password/) 完成绑定。

双层密码和登录密码有什么区别

登录密码用于登录账号；双层密码也叫二次密码，用于登录后对高风险操作做额外确认。

双层密码需要账号已经设置普通登录密码后才能启用。建议不要把它设置成和登录密码完全一样。详情见 [双层密码（二次密码）](/docs/site-info/double-password/)。

为什么系统提示我要先绑定手机号

这是单独的大陆手机号绑定策略。当前访问地区如果被判定为中国大陆，而站点又对该动作启用了手机号前置条件，就会先要求绑定手机号。

详情见 [安全前置条件](/docs/site-info/security-prerequisites/) 和 [手机号绑定](/docs/site-info/phone-binding/)。

## 投稿与审核

为什么我的内容需要审核

帖子、资源、找服玩服务器和视频投稿都可能进入审核队列。审核用于确认内容是否符合站点规范、分类是否正确、链接是否安全，以及是否存在广告、侵权或违规信息。

草稿和待审核有什么区别

| 状态 | 含义 |
| --- | --- |
| `draft` | 草稿，仅作者可见，通常不会进入公开列表。 |
| `pending` | 已提交审核，等待版主或管理员处理。 |
| `approved` | 审核通过，公开展示。 |
| `rejected` | 审核未通过，需要修改后重新提交。 |

已公开内容再次编辑后为什么又进入审核

对已公开内容进行关键字段更新时，系统可能重新进入审核流程。常见触发项包括标题、正文、下载链接、分类、封面、视频链接等。

## 内容与互动

点赞、收藏、评论会公开吗

点赞、收藏和评论的展示方式取决于具体页面。评论和回复通常是公开互动；收藏可能只在个人空间或自己的列表中展示。

可以删除自己的内容吗

不同内容类型的删除能力可能不同。部分内容只允许编辑或设为草稿，不能直接删除；涉及审核记录、公开讨论或安全记录的内容，可能需要管理员处理。

为什么看不到某篇帖子

可能原因包括：

-   内容还在草稿或审核中。
-   内容被作者设置了可见性或访问密码。
-   内容被锁定、隐藏或移入处理流程。
-   你没有对应板块或内容的访问权限。

为什么推广链接打不开或加载失败

推广邀请功能当前需要两层条件：

-   站点已开启该功能
-   你的账号已解锁推广能力

按默认实现，推广能力和入站考试有关。可以先看 [推广邀请](/docs/site-info/referral-program/) 和 [考试中心](/docs/site-info/exam-center/)。

为什么 API Token 区域还没开放

当前个人 API Token 需要先通过开发者考试对应门槛。详情见 [考试中心](/docs/site-info/exam-center/) 和 [用户个人 API](/docs/api/personal-api-tokens/)。

私信和通知有什么区别

私信是实际的聊天内容，通知是站内提醒。你收到一条私信时，通常既会在消息中心里看到会话，也可能在通知中心里看到“私信提醒”。

详情见 [消息中心](/docs/site-info/messages-center/) 和 [通知中心](/docs/site-info/notifications-center/)。

为什么删除私信后对方还能看到

当前前台的“删除（仅自己可见）”是本地隐藏，不是替双方真正删除消息。真正能影响双方显示的是私信撤回，而且目前只支持自己发送后 2 分钟内撤回。

详情见 [消息中心](/docs/site-info/messages-center/)。

## 私信与通知

为什么收不到通知

请检查：

-   账号通知开关是否关闭。
-   邮箱通知是否启用并完成验证。
-   浏览器推送权限是否被拒绝。
-   内容是否实际触发了通知事件。

为什么某个第三方站点突然不能继续读取我的资料了

常见原因是你已经在“已授权第三方站点”里撤销了它的授权。撤销后，旧的访问令牌和刷新令牌都会失效，对方需要重新让你授权。

详情见 [账号绑定与已授权第三方站点](/docs/site-info/account-connections/)。

为什么我移除登录设备后自己也被登出了

因为你移除的是“当前设备”对应的登录会话。当前实现里，移除当前设备会直接清掉本机登录状态，并回到登录页。

详情见 [登录设备管理](/docs/site-info/login-device-management/)。

为什么删密码前要先绑定通行密钥

当前站点的无密码模式要求账号至少已经绑定一把通行密钥。这样删除密码后，仍然保留一条可用登录路径。

详情见 [通行密钥](/docs/site-info/passkeys/)。

为什么 2FA 备用码找不到了

备用码不会反复完整展示。当前实现里，它们更像一次性应急凭据，所以启用或重置后应该立即下载并离线保存。

详情见 [二步验证（2FA）](/docs/site-info/two-factor-auth/)。

为什么邮箱设置一上来不是让我验证旧邮箱，而是直接填新邮箱

常见原因是当前账号使用的是第三方登录占位邮箱，系统不会把它当作真正可接收邮件的旧邮箱，因此会直接进入补齐新邮箱流程。

详情见 [邮箱设置](/docs/site-info/email-settings/)。

私信可以被举报吗

如果私信存在骚扰、诈骗、广告导流、恶意链接或其他违规内容，应通过站点提供的举报入口提交。管理员会根据记录处理。

## 搜索与统计

搜索结果为什么不完整

搜索通常只展示你有权限查看的公开内容。草稿、待审核、隐藏、私密或受限内容不会正常出现在公开搜索结果中。

首页统计为什么会延迟

首页社区统计存在缓存。资源总数、帖子总数、今日新发和在线人数不一定实时刷新，短时间内存在延迟属于正常情况。

## 安全与违规

被封禁后怎么办

先查看站内通知或提示中的封禁原因。如果认为处理有误，可以按站点申诉渠道联系管理员。申诉时请说明账号、涉及内容、时间和你的解释。

发现违规内容怎么办

优先使用举报功能。举报时尽量提供明确原因，不要在评论区继续争吵或扩大冲突。

什么内容容易被拒绝

常见原因包括：

-   标题或正文过短，无法说明内容。
-   下载链接不可访问或存在风险。
-   分类选择错误。
-   未说明转载、授权或依赖关系。
-   广告、引流、诈骗、恶意链接或侵犯他人权益。
