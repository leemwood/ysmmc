# 登录设备管理

说明如何查看当前账号的登录设备、识别当前设备，以及移除指定设备后的实际效果。

## 这是什么

登录设备管理用于查看当前账号有哪些仍处于登录状态的设备，并按需移除它们。

当前入口在：

```
/settings?tab=devices
```

## 页面会显示什么

当前设备列表会展示这些信息：

-   设备或浏览器的大致标识
-   登录 IP
-   登录时间
-   最近活跃时间
-   是否为“当前设备”

如果当前没有任何可展示的登录会话，页面会提示“暂无已登录设备”。

## 可以做什么

当前用户侧支持两件事：

| 动作 | 说明 |
| --- | --- |
| 刷新 | 重新拉取当前设备列表 |
| 移除 | 强制某个设备下线 |

## “当前设备”是什么意思

设备列表里会有一个“当前设备”标记，表示你现在正在使用的这次登录会话。

移除它和移除其他设备的区别是：

| 操作对象 | 结果 |
| --- | --- |
| 其他设备 | 对方设备会被强制下线 |
| 当前设备 | 你自己会立刻退出登录，并跳回登录页 |

## 标准使用路径

1.  进入“设置 -> 登录设备”。
2.  查看所有仍处于登录状态的设备。
3.  找到不认识的设备或不再使用的设备。
4.  点击“移除”。
5.  确认移除后，该设备会被强制下线。

## 什么时候应该移除设备

这些场景尤其适合用这个功能：

-   你曾在公共电脑登录过
-   更换了旧手机或旧电脑
-   怀疑账号被他人登录过
-   只是想主动收敛会话数量

## 和改密码、2FA、通行密钥的关系

登录设备管理只能处理“已经登录着的会话”。

如果你怀疑账号安全有风险，通常更稳妥的顺序是：

1.  移除异常设备
2.  修改密码
3.  绑定 2FA 或通行密钥

## 常见失败原因

展开查看登录设备管理常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 列表加载失败 | 登录状态已失效，或请求失败 | 重新登录后再查看 |
| 移除后自己被踢下线 | 你移除的是当前设备 | 属于预期行为 |
| 看不懂设备名称 | 前台只会显示简化后的浏览器/设备标识 | 结合 IP 和活跃时间判断 |
| 移除后设备又出现 | 该设备重新登录了 | 结合密码修改和 2FA 进一步处理 |

## 疑难解答

### 能一次性移除所有设备吗？

按当前用户侧实现，没有单独的“一键退出全部设备”按钮，需要逐个移除。

### 移除设备会删除我的内容吗？

不会。它只影响登录会话，不会删除账号数据。
