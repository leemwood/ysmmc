# 账号绑定与已授权第三方站点

说明账号绑定页能做什么、第三方登录绑定与撤销授权的区别，以及当前已开放的相关能力。

## 这是什么

账号绑定页用于管理两类不同关系：

1.  你的 NexusMC 账号绑定了哪些第三方登录账号
2.  你授权过哪些第三方站点读取本站账号资料

当前入口在：

```
/settings?tab=oauth
```

## 两类关系有什么区别

这两者名字很像，但不是同一件事。

| 类型 | 作用 |
| --- | --- |
| 账号绑定 | 让你用 GitHub、Microsoft、QQ 等第三方账号登录 NexusMC |
| 已授权第三方站点 | 允许别的站点通过本站 OAuth2 读取你的部分资料 |

简单说：

-   “账号绑定”是你把外部账号接进 NexusMC
-   “已授权第三方站点”是你把 NexusMC 账号授权给外部站点使用

## 当前页面会显示什么

账号绑定分区当前会显示：

-   当前已启用的第三方登录方式
-   每个方式是否已绑定
-   已绑定时的展示名、邮箱或绑定时间
-   已授权第三方站点列表

如果某个第三方登录方式没有在站点后台启用，它不会出现在可绑定列表里。

## 第三方登录绑定

当前前台会根据站点启用情况显示可绑定的提供方，例如：

-   GitHub
-   Microsoft
-   Google
-   Apple
-   Discord
-   QQ
-   BiliBili
-   GeeID OAuth
-   NatayarkID OAuth

实际看到哪些，以当前站点配置为准。

### 绑定后能做什么

绑定成功后，通常可以：

-   用该第三方账号直接登录 NexusMC
-   减少密码登录频率
-   让账号找回和后续验证路径更多一些

### 解绑后会怎样

解绑后，该第三方账号不再能直接登录你的 NexusMC 账号。

但要注意：

-   解绑第三方登录，不等于删除你的 NexusMC 账号
-   如果你的账号还依赖其他登录方式，建议先确认仍然能正常登录

## Microsoft 正版验证

按当前实现，Microsoft 绑定区还可能承载一个额外能力：Minecraft 正版验证。

如果站点启用了相关功能，并且 Microsoft OAuth 已可用，你可能会看到：

-   验证正版
-   重新验证正版
-   已验证状态

通过后，系统可以自动授予“正版玩家”徽章。

NOTE

这部分属于站点可选功能，不是所有部署都会开放。

## 已授权第三方站点

这一部分显示的是你曾同意通过“本站 OAuth2”读取资料的第三方应用。

列表通常会包含：

-   应用名称
-   应用说明
-   授权 scope
-   创建时间
-   最近使用时间

## 撤销授权会发生什么

当你撤销某个第三方站点授权后：

-   该应用已有的 `access_token` 会失效
-   该应用已有的 `refresh_token` 也会失效
-   该第三方站点如果还想继续访问你的资料，需要重新让你授权

这和“解绑第三方登录账号”是不同操作，不要混用。

## 标准使用路径

### 如果你想绑定第三方登录

1.  打开“设置 -> 账号绑定”。
2.  找到已启用的第三方登录提供方。
3.  点击绑定并完成外部授权。
4.  返回设置页确认绑定结果。

### 如果你想撤销某个外部站点的资料读取权限

1.  打开“设置 -> 账号绑定 -> 已授权第三方站点”。
2.  找到对应应用。
3.  执行撤销授权。
4.  如有需要，到第三方站点重新发起授权。

## 常见失败原因

展开查看账号绑定常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| 想绑定但页面没有该提供方 | 该登录方式未启用或未正确配置 | 以当前站点配置为准 |
| 绑定失败 | 外部授权失败、账号冲突或站点配置异常 | 重新发起绑定，必要时联系管理员 |
| 撤销授权后第三方站点无法登录 | 撤销后旧 Token 会失效 | 到第三方站点重新授权 |
| 解绑后登录不了 | 账号缺少其他可用登录方式 | 解绑前先确认密码、邮箱或其他绑定仍可用 |

## 疑难解答

### 绑定 GitHub 和授权某个第三方站点，是同一个“OAuth”吗？

底层都和 OAuth 有关，但在用户操作层面不是同一件事：前者是登录绑定，后者是授权别的站点读你的本站资料。

### 撤销已授权第三方站点，会不会把我绑定的 GitHub 一起删掉？

不会。这是两套独立记录。
