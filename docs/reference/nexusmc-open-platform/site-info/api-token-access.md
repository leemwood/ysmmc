# 个人 API Token 开放条件

说明为什么设置页里会出现 API Token 门槛提示、开发者考试与 Token 管理能力的关系，以及用户侧应该怎么处理。

## 这是什么

“个人 API Token”是给你自己的脚本、同步工具和自动化流程使用的受限令牌。

用户侧入口在：

```
/settings?tab=api
```

但这个入口不是对所有账号无条件开放。

## 当前开放门槛

按当前实现，个人 API Token 的站内设置页管理能力受开发者考试控制。

也就是说，只有当账号解锁了 `create_api_token` 能力后，设置页里的这些操作才会开放：

-   查看可选 scope
-   查看已有 Token 列表
-   创建 Token
-   编辑 Token
-   撤销 Token

## 这个能力怎么解锁

当前默认方式是：

1.  进入 [考试中心](/docs/site-info/exam-center/)
2.  参加开发者考试
3.  分数达到当前门槛
4.  返回设置页使用 API Token

按默认配置，开发者考试当前门槛是 `80` 分。

开发者考试同时会解锁 `publish_content`，但这不表示 Token 创建和内容发布是同一项权限：

-   创建和管理 Token 只要求 `create_api_token` 已解锁。
-   使用 Token 正式投稿还要求账号确认当前版本的创作者协议。

创作者开通步骤见 [创作者开通与协议确认](/docs/site-info/creator-onboarding/)。

## 为什么会看到“开发者考试尚未达标”

设置页 API Token 分区当前会显示专门的考试门槛提示卡。

它的意思不是：

-   页面坏了
-   站点 API 整体关闭了
-   你的账号被封禁了

它真正表示的是：**当前账号还没有达到个人 API Token 的开放条件。**

## 和 API 文档是什么关系

这里说的是“你有没有资格在站内设置页管理 Token”。

[用户个人 API](/docs/api/personal-api-tokens/) 说的是“拿到 Token 之后，具体怎么用接口”。

可以这样理解：

| 文档 | 解决什么问题 |
| --- | --- |
| 本文 | 为什么当前账号还不能在设置页管理 Token |
| [用户个人 API](/docs/api/personal-api-tokens/) | Token 创建后如何调用接口 |

## 当前管理页能做什么

开发者考试达标后，设置页里的 API Token 分区当前支持：

-   新建 Token
-   选择 scope
-   选择有效期
-   查看最近使用时间和最近使用 IP
-   编辑名称、scope 和有效期
-   吊销已有 Token

创建成功后，完整 Token 明文当前只会展示一次。

## 常见失败原因

展开查看 API Token 门槛常见问题

| 场景 | 原因 | 处理方式 |
| --- | --- | --- |
| API Token 分区显示未开放 | 开发者考试未达到要求 | 先去考试中心 |
| 创建按钮是灰的 | 当前仍处于考试门槛状态 | 通过开发者考试后重试 |
| 看不到 scope 列表 | 后端会在门槛未满足时拒绝返回 scope | 先解锁 `create_api_token` 能力 |
| 已通过考试但仍打不开 | 页面缓存或状态尚未刷新 | 刷新设置页，必要时重新登录 |

## 疑难解答

### 通过开发者考试后，会自动给我一个 Token 吗？

不会。考试只负责开放管理能力，Token 仍需要你自己手动创建。

### 通过开发者考试后，能直接操作后台吗？

不能。开发者考试当前会解锁个人 API Token 能力和创作者发布流程，但不授予后台权限。

### 创建 Token 前必须先确认创作者协议吗？

不需要。创建 Token 与确认协议是独立步骤；但使用 Token 正式发布内容时，服务端会继续检查完整创作者资格。
